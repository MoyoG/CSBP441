Instructions

Show your method

Use degrees for gradient direction. Unless stated otherwise, use the kernel conventions given in each question and round non-integer answers to two decimals.

1. Gradient magnitude and direction

Given Gx = 30 and Gy = 40, calculate gradient magnitude and direction.

Answer: M = sqrt(30 squared + 40 squared) = 50. theta = atan2(40,30) = 53.13 degrees.

2. Canny classification

For Tlow = 50 and Thigh = 100, classify a pixel with M = 72. State when it remains after hysteresis.

Answer: It is weak because 50 less than or equal to 72 is less than 100. It remains only when connected to a strong edge.

3. Constant-region response

Explain why a zero-sum Sobel derivative kernel produces zero response on a constant image region.

Answer: Every neighborhood value is equal, so the positive and negative kernel weights cancel. A derivative measures change, and a constant region has no change.

4. Horizontal intensity step

Use Gy = [[-1,-2,-1],[0,0,0],[1,2,1]] on the patch [[10,10,10],[10,10,10],[90,90,90]]. Calculate the response and identify the boundary orientation.

Answer: Response = -40 + 360 = 320. Gy responds to the change from top to bottom, so the image contains a horizontal boundary.

5. Vertical intensity step

Use Gx = [[-1,0,1],[-2,0,2],[-1,0,1]] on the patch [[10,10,90],[10,10,90],[10,10,90]]. Calculate the response and identify the boundary orientation.

Answer: Response = 4(90 - 10) = 320. Gx responds to a left-to-right change, so the image contains a vertical boundary.

6. Gradient sign

With the one-dimensional kernel [-1,0,1], predict the sign for the row [200,200,50].

Answer: -200 + 50 = -150. The negative sign indicates intensity decreases from left to right under this convention.

7. Gradient direction and edge tangent

A pixel has Gx = -50 and Gy = 50. Find the direction. Is the local edge tangent parallel or perpendicular to this direction?

Answer: theta = atan2(50,-50) = 135 degrees. The edge tangent is perpendicular to the gradient direction.

8. Non-maximum suppression

Along the gradient direction, three neighboring magnitude values are 36, 82, and 70. Which value survives non-maximum suppression?

Answer: 82 survives because it is the local maximum along the gradient direction.

9. Weak-edge hysteresis

For Tlow = 40 and Thigh = 120, a pixel has magnitude 80. It is connected through 8-neighborhood links to a magnitude-160 pixel. Does it remain?

Answer: Yes. Magnitude 80 is weak, and the 160-pixel is strong. The weak pixel is retained through connectivity.

10. Rejected weak edge

For Tlow = 40 and Thigh = 120, a pixel has magnitude 80 but is disconnected from every strong pixel. Does it remain?

Answer: No. It is a weak candidate but is rejected by hysteresis because it lacks a connection to a strong edge.

11. LoG zero crossing

A LoG neighborhood has values [-3,-1,2,4]. Does it contain a zero crossing? Name one additional acceptance condition.

Answer: Yes, the response changes sign. Also require sufficient local contrast or magnitude difference to reject small noise-driven sign changes.

12. Smoothing tradeoff

Increasing Gaussian sigma from 0.5 to 3.0 removes many speckle responses but makes a thin wire boundary disappear. Explain the tradeoff.

Answer: Larger sigma suppresses high-frequency noise but also attenuates fine structures and reduces localization. A smaller or moderate sigma may better preserve the wire.

13. Direct versus separable Gaussian cost

Compare multiplication counts for a 5 x 5 Gaussian on a 512 x 512 image using direct filtering and two separable 1D passes.

Answer: Direct cost is 25 x 512 squared = 6,553,600 multiplications. Separable cost is 10 x 512 squared = 2,621,440. Separable filtering uses 60 percent fewer multiplications.

14. Image-size scaling

A fixed 3 x 3 Sobel pipeline takes 12 ms for a 640 x 480 image. Estimate the time for 1280 x 960, assuming linear scaling and unchanged hardware.

Answer: The second image has four times as many pixels, so the estimated time is 48 ms.

15. Threshold choice

A Canny result with thresholds 30 and 90 contains many texture edges. Thresholds 70 and 180 remove texture but miss a required faint boundary. Give one justified adjustment.

Answer: Test intermediate thresholds, for example 50 and 140, and inspect recall of the required boundary. Moderate smoothing may also reduce texture before applying a less aggressive threshold.

16. Sobel versus Scharr

A small 3 x 3 derivative detector gives noticeably different responses when a diagonal edge is rotated. Which operator is a reasonable alternative, and why?

Answer: Scharr is a reasonable alternative because its 3 x 3 weights improve rotational behavior and derivative accuracy compared with standard Sobel.

17. Edge-map evaluation

A predicted edge map has 90 pixels, of which 60 match a 75-pixel reference edge mask. Calculate precision and recall.

Answer: Precision = 60/90 = 0.67. Recall = 60/75 = 0.80.

18. Edge overlay interpretation

A Canny map is overlaid in red on the original image. Does this operation alter the detector output? What is its practical purpose?

Answer: No. It only visualizes the already computed map. It helps assess whether detected pixels align with useful image boundaries.

19. Practical detector selection

Choose a detector for real-time lane-boundary preprocessing on a moderately noisy video stream. Give a concise pipeline and one evaluation measure.

Answer: A valid answer is grayscale conversion, moderate Gaussian smoothing, Canny, region-of-interest masking, and line fitting or tracking. Evaluate boundary precision/recall against labeled frames or downstream lane-detection stability and FPS.

20. Failure analysis

An inspection system detects every textured label on a product but misses a low-contrast crack. Identify two likely causes and two remedies.

Answer: Likely causes include unsuitable thresholds, inadequate contrast, excessive smoothing, or texture responses. Remedies include local contrast enhancement, tuned smoothing and Canny thresholds, region-of-interest restriction, or a learned defect detector after classical preprocessing.
