What this tests

Secure flow

  1. IdentificationThe entered student ID or username must exist in the uploaded roster.
  2. EnrollmentThe roster determines whether that identifier belongs to this class.
  3. PresenceThe student enters the rotating code visible in the room.
  4. UniquenessOnly one check-in is accepted per student and session.
Important limitation

Without institutional login, an entered ID does not prove who is holding the phone. The rotating in-room code reduces remote check-ins but cannot prevent ID sharing.
